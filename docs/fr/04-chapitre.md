# 4. Gouvernance et limites

Les rôles contrôlent la sélection des actifs, les stratégies et les pauses. Les risques principaux concernent les oracles, les pertes de stratégie, les upgrades et les dépendances externes.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
